# Ilvuno Brand Identity Assets

This folder contains all vector SVG assets for the Ilvuno brand identity explorations, refinements, and typography-led wordmarks.

All assets are standalone, zero-dependency, scalable SVGs configured with `currentColor` fills and transparent backgrounds.

## File Directory

### Refinements & Recommendations
- **`ilvuno-concept-c.svg`**: Refined architectural IV monogram lockup (`viewBox="0 0 300 80"`).
- **`ilvuno-concept-c-icon.svg`**: Refined IV monogram standalone icon (`viewBox="0 0 100 100"`).
- **`ilvuno-concept-e.svg`**: Refined single-step seam lockup in solid monochrome (`viewBox="0 0 296 80"`).
- **`ilvuno-concept-e-icon.svg`**: Refined single-step seam square monolith icon (`viewBox="0 0 100 100"`).
- **`ilvuno-wordmark-slim.svg`**: Standalone slim custom Ilvuno wordmark (`viewBox="0 0 250 88"`).
- **`ilvuno-wordmark-slim-icon.svg`**: Typographic `Il` monogram badge (`viewBox="0 0 100 100"`).

### Initial Concept Set
- **`ilvuno-concept-a.svg`** / **`ilvuno-concept-a-icon.svg`**: Bold custom engineered wordmark and `Il` seal.
- **`ilvuno-concept-b.svg`** / **`ilvuno-concept-b-icon.svg`**: The Convergent Keel chevron and spine mark.
- **`ilvuno-concept-d.svg`** / **`ilvuno-concept-d-icon.svg`**: The Integration Pylon architectural mark.

### Interactive Previews
- **`overview.html`**: Interactive side-by-side showcase of Concepts A–E across dark and light palettes and micro-scales (16px to 64px).
- **`refinements_overview.html`**: Interactive showcase of the Refined IV Monogram, Simplified Seam, and Slim Wordmark.
