# T-0605 — CLI completion, JSON contract, docs, v0.1.0

Milestone: M6 · Estimate: 2 d · Owner: both · Provisional: no

## Goal
Ship it: complete the surface, freeze the JSON contract, write the docs a stranger needs, and release
v0.1.0 through gate G6.

## Dependencies
T-0601..T-0604; all previous gates. `OSS-101`..`OSS-104`, PRD §26, `05-release-gates.md` §11.

## Allowed file scope
- `internal/cli/**` (completion + help text)
- `internal/cli/help_test.go`
- `docs/` (quickstart, configuration, troubleshooting, non-claims)
- `README.md`, `CHANGELOG.md`, `Makefile` (release targets)
- `.goreleaser.yaml`, `.github/workflows/release.yml`

**May not touch:** engine semantics (no last-minute behaviour changes); schemas except additive fixes.

## Implementation outline
1. Complete commands and global flags per architecture `01` §6; every command has `--help`, exit code,
   and `--json` where meaningful.
2. Help-text test: `--help` output matches `docs/cli.md` (single source; drift fails CI).
3. Freeze `ilvuno.dev/report/v1`, `findings/v1`, `passport/v1`, `bundle/v1`, `journal/v1`;
   publish `ilvuno schema <kind>`.
4. Docs: 10-minute quickstart (tested on a clean VM), config reference (every key, default, refusal),
   troubleshooting (error code → action table), "what this does not prove" page linked from README,
   `init` output, and the report footer.
5. Release: goreleaser for darwin/linux × arm64/amd64, checksums, no CGO; `CHANGELOG.md` in user terms.
6. G6 packet: traceability matrix (every P0 requirement → test or recorded manual check), outsider
   session log, benchmark table vs BL-1/2/3.
7. Tag `v0.1.0` only after G6 sign-off.

## Test commands
```
make test && make lint && make bench && make docs-check
make release-check
```

## Evidence requirements
Traceability matrix, outsider session recording, bench.json, checksums, clean-VM install log,
the G6 packet.

## Review checklist
- Does any doc claim exceed the banned-claims list?
- Is every error code in the troubleshooting table?
- Does the quickstart work with a repo that has zero tests (the honest path)?
- Is the release reproducible from the tagged commit?
