# T-0304 — Evidence store, redaction, bundle verify

Milestone: M3 · Estimate: 2 d · Owner: B · Provisional: no

## Goal
Evidence that outlives the binary: content-addressed records and logs, redacted at write, sealed into
a bundle that anyone can verify offline.

## Dependencies
T-0301. ADR-0009, `EVD-101`..`EVD-107`, `INV-13`.

## Allowed file scope
- `internal/evidence/**`
- `internal/redact/**`
- `schemas/{bundle,journal}.schema.json` (bundle half)
- `docs/evidence-format.md`

**May not touch:** `internal/verify` (produces records via the API), `internal/cli`.

## Implementation outline
1. `Append(record)`: content-addressed, `prev_digest` chain, `seq`; blobs written to
   `bundles/<id>/logs/` with size cap.
2. Redaction pipeline (`redact` package): classes `pattern`, `entropy`, `user`; applied to any byte
   stream before write; marker `«redacted:<class>»`; config-supplied regexes compiled at load.
3. Bundle seal: write to `bundle.tmp/`, fsync files + dir, `rename` to final; manifest lists every
   file with `sha256` + `bytes`; `manifest_digest` over the canonical manifest body.
4. `Verify(path)`: schema check, per-file digest recompute, unlisted-file detection, manifest digest
   recompute; returns `valid | invalid(reason)`.
5. `Verify` must work with no repo and no network.
6. Tests: tamper each artifact type; truncate logs; remove a file; add an extra file.

## Acceptance criteria
| AC | Statement |
|---|---|
| AC-1 | A one-byte log edit fails verify with `invalid(log)` |
| AC-2 | An added file is reported as unlisted (not silently accepted) |
| AC-3 | Verify passes with the binary removed from PATH (pure file + hashes) |
| AC-4 | Redaction corpus (200 secrets / 200 benign) passes both directions (RED-1) |
| AC-5 | No env value appears in any artifact (asserted by scanning a fixture run) |
| AC-6 | Seal interruption leaves `bundle.tmp` only, never a half-valid bundle |
| AC-7 | `--keep-raw` is refused when bundling (asserted) |

## Test commands
```
go test ./internal/evidence/... ./internal/redact/... -count=1 -v
PATH=/usr/bin:/bin go test ./internal/evidence/ -run TestVerifyNoBinary -count=1
```

## Evidence requirements
Tamper matrix (artifact → result), corpus report, a sample bundle tree with manifest excerpt.

## Review checklist
- Is redaction applied before write on every path (including error logs)?
- Does the manifest cover *every* file, or only the ones the author remembered?
- Is `manifest_digest` computed over a canonical form (stable key order)?
- Can a record with `status: passed` exist without a bound SHA? (must be impossible)
