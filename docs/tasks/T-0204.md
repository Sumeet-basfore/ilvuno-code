# T-0204 — merge-tree preflight (pairs + tuple)

Milestone: M2 · Estimate: 1.5 d · Owner: B · Provisional: no

## Goal
Detect conflicts without mutating anything: pairwise and full-tuple, with results explicitly marked
as predictions and reconciled later against the real merge.

## Dependencies
T-0101 (`MergeTree`), T-0104 (pinned SHAs), T-0005 (E-1 verdict).

## Allowed file scope
- `internal/analyze/preflight.go`
- `internal/model/finding.go` (conflict finding variant only; coordinate with T-0301)

**May not touch:** `internal/engine` candidate construction, `internal/verify`.

## Implementation outline
1. Pairwise: for each pair with overlapping or unknown file sets, `merge-tree --write-tree --name-only
   base a b`; parse conflicts (paths + stage entries).
2. Tuple: one call with all SHAs; parse the same way. This is the case that pairs miss.
3. If `merge_tree` capability is absent: return `preflight: unavailable (git < 2.38)` and let the
   caller decide (default: proceed with a report note; `--require-preflight` refuses).
4. Findings: `merge_conflict` with `predicted: true`, `sources[]`, `paths[]`, `classification:
   deterministic`. Severity blocking by default.
5. Cost guard: skip pairs with disjoint file sets (computed from `diff --name-only`), record the skip
   count in the report so a reader knows the search was bounded.
6. Reconciliation hook: after a real merge, compare prediction vs reality and emit
   `prediction_mismatch` (a bug-level finding) if they disagree.

## Acceptance criteria
| AC | Statement |
|---|---|
| AC-1 | Pairwise and tuple predictions match real merges on the 200-case corpus (or mismatches are recorded as `prediction_mismatch`) |
| AC-2 | Triple-only conflict is predicted when E-1 was positive; when negative, the report says `preflight: pair-only` |
| AC-3 | No worktree, ref, or file is created by preflight (fingerprint + ref diff) |
| AC-4 | Predictions carry `predicted: true` and never claim to have merged |
| AC-5 | Skipped pairs (disjoint file sets) are counted and reported |
| AC-6 | Preflight runs in ≤ 800 ms on 5 to 20k-file sources |

## Test commands
```
go test ./internal/analyze/ -run TestPreflight -count=1 -v
make bench SCENARIO=B-02; make bench SCENARIO=B-03
```

## Evidence requirements
Prediction-vs-reality table for the 200-case corpus, timing, a report snippet showing `predicted`.

## Review checklist
- Does any code path merge during preflight? (it must not)
- Is a mismatch silent? (must be a finding, not a log line)
- Are paths reported repo-relative?
- Is the bounded-search skip visible to the reader?
