# T-7001 — Adapter interface + conformance harness *(provisional)*

Milestone: M7 · **Provisional — not approved.** Estimate: 3 d · Owner: B

## Goal
If dispatch is ever approved, the boundary already exists: a narrow adapter interface with
capability validation, a normalized event union, and recorded-transcript conformance fixtures.

## Dependencies
M6 gate (G6), ADR-0010, a user request for dispatch. `ORQ-105` design gate.

## Allowed file scope
- `internal/agent/**`
- `internal/testkit/conformance/**`
- `schemas/agent-event.v1.json`

**May not touch:** `internal/engine` (import rule forbids it, `T-0001` AC-3).

## Outline (sketch)
1. `Adapter` interface per `architecture/03` §4; capability set validated against implementation at
   construction.
2. `Event` union per `03` §5; provider raw frames confined to a rotating diagnostic log.
3. Conformance harness: recorded transcript files replayed; assertions on events, not on text.
4. Cancellation ladder + ownership record (pid, start_time, boot_id); kill only our own processes.
5. Refusal paths: `provider_auth_required`, `provider_unsupported_env`, `provider_protocol_mismatch`.

## Acceptance criteria (provisional)
- Declaring a capability without an implementation is a startup error.
- A replayed transcript produces the expected normalized events with zero live model calls.
- `engine` still has no dependency on `agent` (import test).
- `AgentRun.state` cannot produce an approval (`INV-7` absence test still passes).

## Test commands
```
go test ./internal/agent/... ./internal/testkit/conformance/... -count=1
go test ./internal/lint/importrule/... -count=1
```

## Evidence requirements
Conformance replay log, capability-validation test, import-rule output.

## Review checklist
- No credential field exists in any struct (`AUTH-1`).
- No PTY or output-text inference anywhere.
- Raw frames never enter evidence.
