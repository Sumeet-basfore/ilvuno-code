# T-0004 — Safety fingerprint helper

Milestone: M0 · Estimate: 0.5 d · Owner: A · Provisional: no

## Goal
A cheap, complete snapshot of everything a user owns in a repository, so every scenario can assert
`INV-1` mechanically instead of by inspection.

## Dependencies
T-0002 (a repo to snapshot).

## Allowed file scope
- `internal/testkit/safety/**`

**May not touch:** production packages.

## Implementation outline
1. `Fingerprint(repo) Fingerprint` covering: non-`refs/ilvuno/` refs (name→sha), `HEAD`, index
   (`ls-files --stage` digest), working tree (`status --porcelain=v2 --untracked-files=all` + content
   digest of modified/untracked files), stashes (`stash list --format=%H`), `.git/config` digest.
2. `Equal(a,b) Diff` returning a readable per-field diff (which ref moved, which file changed).
3. Tests: mutate each field once and assert the diff names it.
4. Must be fast: target ≤ 50 ms on a 500-file fixture.

## Acceptance criteria
| AC | Statement |
|---|---|
| AC-1 | Detects: ref move, new ref, branch delete, staged change, dirty file, untracked file, stash, config edit |
| AC-2 | Ignores `refs/ilvuno/*` changes by design (so candidate creation is not a false positive) |
| AC-3 | Diff output names the field and both values |
| AC-4 | ≤ 50 ms on the 500-file fixture |
| AC-5 | No false positives across 20 consecutive runs of an empty operation |

## Test commands
```
go test ./internal/testkit/safety/... -count=1 -v
```

## Evidence requirements
Table: mutation → detection output. Timing line.

## Review checklist
- Does it cover index and stashes, not just `git status`?
- Is the digest stable across two runs with no change? (Linux/macOS differ in `status` output — test both)
- Does it accidentally include `.ilvuno/`?
