# T-0501 — Uncertainty model, `resume`, `abort`

Milestone: M5 · Estimate: 2 d · Owner: A · Provisional: no

## Goal
Never guess after a crash: name what is unknown, require an explicit decision, and make `abort` safe.

## Dependencies
T-0201 (journal), T-0205 (merge), T-0404 (verify). `REC-101`..`REC-104`, `INV-4`, architecture `08` §4.

## Allowed file scope
- `internal/engine/recovery.go`, `internal/engine/uncertainty.go`
- `internal/cli/resume.go`, `internal/cli/abort.go`
- `internal/model/uncertainty.go`
- `docs/recovery.md`

**May not touch:** journal format (T-0201 owns it).

## Implementation outline
1. On start, classify the last record: intent without result → uncertainty of the corresponding kind;
   result → continue; corrupt → refuse.
2. Four uncertainty kinds: `merge_outcome_unknown`, `verify_outcome_unknown`, `bundle_write_unknown`,
   `cleanup_unknown`.
3. `resume` with no `--decide` prints the list + options, exits 2. With `--decide=<kind>=<action>`
   (repeatable) applies each.
4. `remerge` = discard worktree+ref, rebuild from pinned SHAs (safe by ADR-0005). `rerun` = new
   `VerificationRun` with `attempt+1`, old evidence retained. `reseal` = rebuild bundle from records.
   `retry`/`leave` for cleanup.
5. `abort`: journal intent, remove worktrees/refs (T-0202 API), archive patches, settle `abandoned`.
6. `resume` refuses if any referenced object is missing, naming the object and the fetch hint.
7. State machine: only `interrupted` is resumable; every other terminal state refuses with its name.

## Acceptance criteria
| AC | Statement |
|---|---|
| AC-1 | SIGKILL between merge intent and result → `interrupted` + `merge_outcome_unknown`; `resume` alone exits 2 |
| AC-2 | `--decide=remerge` yields the same candidate SHA as an uninterrupted run |
| AC-3 | `rerun` creates `attempt: 2`, retains attempt 1 marked incomplete |
| AC-4 | No automatic resolution exists; a test asserts `resume` never proceeds without decisions |
| AC-5 | `abort` leaves no worktree, ref, or child process; fingerprint unchanged except `.ilvuno/` |
| AC-6 | Resume on a terminal state refuses naming the state |
| AC-7 | Resume with a missing object names it and suggests `git fetch` |

## Evidence requirements
Transcripts for the three crash kinds, an abort fingerprint diff, a refusal transcript.

## Review checklist
- Is there any code path that resolves an uncertainty implicitly (timeout, retry, "best effort")?
- Does `remerge` delete evidence that already exists?
- Does `abort` ever delete something it did not create?
- Is the uncertainty list durable (in the journal) rather than in memory?
