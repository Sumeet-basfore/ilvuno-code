# T-0602 — Approval gate + key init

Milestone: M6 · Estimate: 1.5 d · Owner: B · Provisional: no

## Goal
The human gate: interactive, digest-bound, unbypassable in non-interactive mode, and verifiable later.

## Dependencies
T-0601, T-0304. ADR-0012, `INT-601`..`INT-604`.

## Allowed file scope
- `internal/approval/**`
- `internal/cli/approve.go`, `internal/cli/key.go`
- `schemas/approval.schema.json`
- `docs/approval.md`

**May not touch:** policy eligibility rules for findings (computed in engine; this consumes them).

## Implementation outline
1. Eligibility function: bundle verifies, all required checks passed, no blocking deterministic finding,
   candidate SHA matches, passport (if linked) not tampered. Returns reasons when ineligible.
2. `approve --run <id>`: require TTY; print candidate SHA, sources, checks, `not_verified`; require the
   user to type the short SHA; then build `Approval{sha, evidence_digest, scope, principal, at}`.
3. Signature: Ed25519 if `~/.config/ilvuno/keys/ed25519.key` exists; else `unsigned: true` and a
   warning line. Write to `.ilvuno/approvals/<id>.json`; append `{id, digest}` to the passport.
4. `key init`: generate Ed25519, write 0600, print the public key fingerprint; refuse to overwrite.
5. Validation on read: record exists, digest matches bundle, SHA matches, chain intact → `valid`;
   otherwise the specific invalidation reason. Never "assume valid".
6. `--json` for CI (refuses: no TTY).
7. `approve --reject` records a rejection with the same binding (so a rejection is also evidence).

## Acceptance criteria
| AC | Statement |
|---|---|
| AC-1 | Non-interactive `approve` refuses (exit 2) with an explanation |
| AC-2 | Wrong typed SHA aborts with no record written |
| AC-3 | Approval binds `(sha, evidence_digest)`; changing either invalidates |
| AC-4 | Any source change after approval → `stale_approval` on next read |
| AC-5 | An unsigned approval is recorded and rendered `unsigned` (visible) |
| AC-6 | Key file is 0600; `key init` refuses to overwrite |
| AC-7 | A forged passport approval entry resolves to no local record → `unverifiable`, gate closed |
