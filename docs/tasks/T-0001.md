# T-0001 — Repo skeleton, toolchain, CI, import-rule harness

Milestone: M0 · Estimate: 1 d · Owner: A · Provisional: no

## Goal
A building, testing, linting Go repository with the package layout from `architecture/01` §3, the
dependency rules from `architecture/01` §3 enforced by a test, and CI that runs on Linux and macOS.
No product behaviour.

## Dependencies
Approvals: `A-1` (CLI), `A-2` (Apache-2.0), `A-3` (Go), `A-4` (no Windows), `A-9` (committed
`ilvuno.toml`). Decision: ADR-0001, ADR-0003.

## Allowed file scope
- `go.mod`, `go.sum`
- `Makefile`
- `.github/workflows/ci.yml`
- `.gitignore`, `.golangci.yml`, `.editorconfig`
- `LICENSE`, `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `README.md`
- `cmd/ilvuno/main.go` (version flag only)
- `internal/{cli,model,gitx,repo,engine,analyze,verify,evidence,passport,policy,proc,redact,journal,config}/` (empty packages with a doc comment)
- `internal/testkit/{forge,safety,fixtures}/` (package stubs)
- `internal/lint/importrule/` (the analyzer)
- `schemas/.gitkeep`
- `docs/planning/gate-log.md` (created, first entry pending)

**May not touch:** any file under `docs/product`, `docs/architecture`, `docs/adr` (read-only inputs).

## Implementation outline
1. `go mod init github.com/<org>/ilvuno`; pin Go version; no third-party deps.
2. `cmd/ilvuno`: `--version` prints `ilvuno dev` and exits 0; `--help` lists planned commands as
   "not implemented in this build" (honest, not fake).
3. Package stubs with a one-line doc comment each, importing nothing.
4. `internal/lint/importrule`: a test-only analyzer asserting the dependency matrix.
5. `Makefile` targets: `build`, `test`, `test-scenario`, `lint`, `bench`, `docs-check`, `gate`.
6. CI: matrix (ubuntu-latest, macos-latest) × (`test`, `lint`); `GIT_CONFIG_GLOBAL=/dev/null`;
   `git --version` printed; fail if < 2.38.
7. License and community files; `.gitignore` includes `.ilvuno/`, `ilvuno` binary, coverage files.

## Acceptance criteria
| AC | Statement |
|---|---|
| AC-1 | `make build` produces a single binary with no runtime deps (`ldd` shows no libgo beyond libc) |
| AC-2 | `make test` passes on a clean clone with `GIT_CONFIG_GLOBAL=/dev/null` and no network |
| AC-3 | `make lint` fails when `engine` imports `agent` (test fixture in the analyzer) |
| AC-4 | CI is green on both OSes and prints the git version |
| AC-5 | `ilvuno --version` exits 0 in ≤ 30 ms |
| AC-6 | README states the product in one paragraph, the non-goals, and a "not usable yet" banner |

## Test commands
```
make build && ./ilvuno --version
make test
make lint
make docs-check
```

## Evidence requirements
CI run link (both OSes), `git --version` output from each, `make lint` demonstration of AC-3
(deliberate violation reverted in the same PR).

## Review checklist
- No dependency added (check `go.mod` has zero `require` entries).
- Package stubs do not import each other.
- CI does not skip on macOS.
- README does not overclaim (see `07-definition-of-done.md` §12).
