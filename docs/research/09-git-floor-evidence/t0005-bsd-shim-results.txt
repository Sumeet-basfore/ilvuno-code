# T-0005: BSD-semantics reproduction of the macOS failures (Linux host; NOT a macOS run)
#
# Shims in t0005-bsd-shim/ are PATH overrides that mimic the BSD behaviour each construct depends on:
#   chmod      "MODE -- FILE" fails (BSD getopt reads "--" as a file name); the file is still changed
#   sed        "-i SCRIPT" fails (BSD takes the next argument as a backup suffix)
#   stat       "-c" fails; "-f FORMAT" is accepted with BSD formats (%u, %Lp)
#   rm         "--version" and "--one-file-system" fail (BSD rm has neither)
#   realpath   absent
#   sha256sum  absent (macOS ships shasum, not sha256sum)
#   shasum     accepts "-a 256" (macOS form)
# They approximate macOS. They do not prove macOS behaviour; the hosted macOS run is still pending.
#
# Run: PATH=<this directory>:$PATH TMPDIR=<private mode-700 dir> bash testdata/reference/check-reference-test.sh
#
